# HabboAirGodzMode

Public **Godz** SWF for Habbo Air.

This repo hosts the `HabboAir.swf` build of the Godz modded Habbo Air client.

## Use with the launcher

1. Install the [Godz custom launcher](https://github.com/godzeth/HabboCustomLauncherGodz).
2. Cycle the update source to **GodzMode**.
3. The launcher downloads the latest `HabboAir.swf` from this repo's [releases](../../releases).

## Releases

The SWF is attached as a release asset on each tagged release. The
`releases/latest/download/HabboAir.swf` endpoint always points to the newest
build. To use it, select the **GodzMode** update source in the launcher.
